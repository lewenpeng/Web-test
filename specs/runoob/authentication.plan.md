# 菜鸟教程首页分类测试计划

## 测试目标

验证菜鸟教程首页可以正常访问，页面标题正确，并确认指定课程分类的首项内容与产品要求一致。

## 测试范围

- 目标地址：`https://www.runoob.com/`
- 覆盖功能：首页加载、页面标题、`Python / 数据科学` 分类、`前端开发` 分类
- 不包含：课程详情页内容、搜索、登录、广告及第三方链接

## 前置条件与环境

- 网络可以访问目标站点，且未被代理或防火墙拦截。
- 使用 Playwright 配置中的 Chromium、Firefox、WebKit 和 mobile 项目执行。
- 执行前设置 `$env:BASE_URL='https://www.runoob.com'`。
- 每个用例从新的浏览器上下文打开首页，避免状态相互影响。

## 测试用例

### RUNOOB-HOME-001：首页标题

**优先级：** P0

1. 访问 `/`。
2. 等待页面 DOM 加载完成。
3. 获取浏览器页面标题。

**预期结果：** 页面成功加载，标题严格等于 `菜鸟教程`。

### RUNOOB-HOME-002：Python / 数据科学分类首项

**优先级：** P0

1. 访问 `/`。
2. 定位并点击标题为 `Python / 数据科学` 的分类。
3. 在该分类容器内获取课程列表的第一项。

**预期结果：** 分类内容可见，第一项标题严格等于 `【学习 Python】`。

### RUNOOB-HOME-003：前端开发分类首项

**优先级：** P0

1. 访问 `/`。
2. 定位并点击标题为 `前端开发` 的分类。
3. 在该分类容器内获取课程列表的第一项。

**预期结果：** 分类内容可见，第一项标题严格等于 `【学习 HTML】`。

## 自动化与判定规则

- 优先使用标题、链接文本和分类容器关系定位，避免依赖易变的 CSS 层级或全页文本匹配。
- 分类标题当前表现为页面区块标题；点击后不要求跳转，只验证对应分类容器及首项内容。
- 文本比较前可去除首尾空白，但不得忽略括号、大小写或内部空格差异。
- 任一断言失败即判定用例失败，并保留截图、视频和 trace；远程站点超时应与内容断言失败区分记录。
